# Formulário de Cadastro de Veículos 🚗

Este repositório contém um formulário de anúncio de veículos desenvolvido com HTML5 e CSS3, focado em organização e facilidade de uso para o usuário final.

## 📋 Características do Projeto

- **Validação Nativa**: Uso de atributos `required`, `minlength` e `maxlength` para garantir a qualidade dos dados inseridos.
- **Seleção Dinâmica**: Sistema de escolha única para câmbio (Radio) e múltipla para opcionais (Checkbox).
- **Upload de Mídia**: Campo configurado para aceitar múltiplas imagens nos formatos JPG e PNG.
- **Feedback Interativo**: Botão de envio com efeitos de transição (hover) que melhoram a experiência de uso.
- **Organização Visual**: Layout em cartões com agrupamento lógico de informações (dados do carro, opcionais e fotos).

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e inputs específicos.
- **CSS3**: Estilização baseada em Box Model, seletores de ID e classe, e efeitos de transição suave.

## 🚀 Como Visualizar

1. Faça o download ou clone do repositório.
2. Abra o arquivo `index.html` em seu navegador de preferência.
